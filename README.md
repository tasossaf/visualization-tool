# Maritime Risk & Navigation Decision Support Dashboard (SLR 40 Studies)

An interactive, academic-grade Decision Support System (DSS) developed to visualize, categorize, and synthesize 40 primary studies on maritime navigational hazards and cybersecurity threats. 

The dashboard bridges real-time vessel traffic data analytics with shipboard Safety Management Systems (SMS) and IMO Resolution MSC.428(98).

## 🚀 How to Run Locally

If you prefer to run or inspect the project locally on your machine:

### Option 1: Direct Execution (Simplest)
1. Clone or download this repository as a `.zip` file and extract it.
2. Double-click **`index.html`** to open it directly in Chrome, Firefox, Safari, or Edge.
*(No web server, dependencies, or installation required).*
